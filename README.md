# SQL ERP Engineer Course

Локальный интерактивный курс SQL для подготовки к собеседованию на ERP Engineer.

## Что внутри

- React + Vite + TypeScript
- Tailwind CSS
- SQL-песочница на `sql.js` и учебной SQLite ERP-базе
- 9 учебных модулей
- 3-дневный план подготовки к ERP Engineer интервью
- разобранные SQL-примеры с объяснением синтаксиса
- тесты, практические задания, ERP-кейсы, финальный экзамен
- прогресс в `localStorage`
- работа без backend-сервера и внешней базы данных
- совместимо с Vercel: учебная база создаётся в браузере, внешняя БД не требуется

## Запуск

```bash
npm install
npm run dev
```

Открой локальный адрес, который покажет Vite, обычно `http://127.0.0.1:5173`.

## Проверка сборки

```bash
npm run lint
npm run build
```

## Локальный запуск двойным кликом

На Windows можно открыть файл `Start SQL ERP Course.bat`. Он запустит Vite и откроет курс в браузере. При закрытии окна `.bat` локальный dev-сервер остановится.
